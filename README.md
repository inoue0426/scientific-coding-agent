# Scientific Coding Agent

A minimal instruction template for scientific Python projects in computational biology and machine learning.

## Start a project

1. Choose **Use this template** to create a new repository, or copy [AGENTS.md](AGENTS.md) into an existing project.
2. Fill in the project context in AGENTS.md: goal, environment, commands, data locations, and evaluation settings.
3. Replace this README with your project's purpose, setup, and usage.

The template keeps the essentials: simple code, reproducible analyses, leakage prevention, fair evaluation, and clear verification. Adapt it to your project and confirm how your coding tool loads instructions.

Python only. No example pipeline or runtime dependencies are included.
